# Cormorant Garamond font source

This directory contains only the Latin webfont subsets used by Penumbra:

- `CormorantGaramond-Regular-latin.woff2` — normal, weight 400
- `CormorantGaramond-Italic-latin.woff2` — italic, weight 400

The WOFF2 files were downloaded from the URLs returned by the official Google
Fonts CSS API for Cormorant Garamond v21:

<https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,400;1,400&display=swap>

Font file URLs:

- <https://fonts.gstatic.com/s/cormorantgaramond/v21/co3umX5slCNuHLi8bLeY9MK7whWMhyjypVO7abI26QOD_v86KnTOig.woff2>
- <https://fonts.gstatic.com/s/cormorantgaramond/v21/co3smX5slCNuHLi8bLeY9MK7whWMhyjYrGFEsdtdc62E6zd58jD-iNM8.woff2>

Upstream metadata and source:

- <https://github.com/google/fonts/tree/main/ofl/cormorantgaramond>
- <https://github.com/CatharsisFonts/Cormorant>

The complete SIL Open Font License 1.1 is retained as `OFL.txt` alongside the
font files. The license file is the copy in the Google Fonts upstream directory;
it was retrieved through jsDelivr's read-only mirror of that repository because
the raw GitHub host was unavailable at download time:

<https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/cormorantgaramond/OFL.txt>
