# Chat UI 交互参考 & 实现备忘

来源：Ant Design X 官方文档及组件 Demo，提取交互模式供 Penumbra 自行实现。
不直接引入 Ant Design X，用 shadcn/ui + Tailwind 手搓，保持设计系统统一。

---

## 1. Bubble 消息气泡

### 交互要点
- 消息分 user / assistant 两种角色，左右布局（user 靠右，assistant 靠左）
- assistant 消息支持 **流式逐字渲染**，光标闪烁提示正在生成
- 消息体支持 Markdown（标题、列表、代码块、链接、图片）
- 代码块右上角有「复制」按钮
- 长消息可折叠/展开
- 每条消息底部有操作栏：复制、重新生成（assistant）、TTS 朗读
- 消息之间有时间分组标记（今天、昨天、更早）

### 实现方向
- 用 `react-markdown` + `remark-gfm` + `rehype-highlight` 渲染 Markdown
- 代码块用自定义 `<pre>` 组件，包裹复制按钮
- 流式渲染：维护一个 `streamingContent` state，SSE/WS 每收到 chunk 就 append
- 生成完成前显示 `▊` 光标闪烁动画
- 折叠：超过 N 行（如 20 行）默认折叠，点击展开

### 待解决
- [ ] 流式过程中 Markdown 语法不完整时的渲染策略（跳过未闭合的代码块？）
- [ ] 长消息折叠的行数阈值

## 2. Conversations 会话列表

### 交互要点
- 左侧栏展示所有会话，按时间倒序
- 每个会话显示：标题（自动截取前 N 字）、最后一条消息预览、时间
- 支持重命名、删除（hover 出现操作按钮）
- 当前会话高亮
- 新建会话按钮在顶部
- 移动端：会话列表作为侧滑抽屉

### 实现方向
- shadcn/ui `ScrollArea` + 自定义列表组件
- 移动端用 `Sheet`（侧滑面板）包裹会话列表
- 删除需要二次确认（shadcn/ui `AlertDialog`）
- 重命名用 inline edit 或 `Dialog`

### 待解决
- [ ] 会话列表是否需要分组（按日期、按角色）
- [ ] 移动端侧滑手势的实现方式（自己写 or 用库）

## 3. Sender 消息输入区

### 交互要点
- 底部固定输入框，自动增高（textarea auto-resize，最大约 6 行）
- 支持附件上传（图片、文件），附件以缩略图预览条显示
- 发送按钮在输入框右侧，有内容时激活，无内容时禁用
- Shift+Enter 换行，Enter 发送（可配置）
- 发送后输入框清空并恢复最小高度
- 生成中显示「停止」按钮替代「发送」

### 实现方向
- `<textarea>` + auto-resize 逻辑（`scrollHeight` 赋值给 `height`）
- 附件预览条用横向 `flex` + 缩略图 + 删除按钮
- 发送/停止按钮用条件渲染，transition 切换图标
- 快捷键在 `onKeyDown` 里判断

### 待解决
- [ ] 附件上传走哪个 API 端点（复用现有 `/api/upload`？）
- [ ] 图片粘贴（clipboard paste）的支持

## 4. ThoughtChain 思考链

### 交互要点
- assistant 回复前展示推理/思考过程（如 RAG 检索了哪些记忆、调用了什么工具）
- 以可折叠的时间线样式展示，每一步有标题 + 状态图标（进行中/完成/失败）
- 默认折叠，用户点击可展开查看详细内容

### 实现方向
- 垂直时间线布局，左侧线条 + 节点图标，右侧内容
- 状态用不同颜色的圆点（灰=待执行、蓝=进行中、绿=完成、红=失败）
- 折叠用 `animate` + `max-height` 过渡

### 待解决
- [ ] 后端是否已经返回 thinking 步骤数据？格式是什么？
- [ ] 是否需要实时展示（流式推进）还是最终一次性展示

## 5. Suggestion 建议卡片

### 交互要点
- 对话开始或 AI 回复后，底部出现 2-4 个建议操作卡片
- 点击直接作为用户消息发送
- 横向滚动，移动端可滑动
- 只在合适时机出现，不是每轮都显示

### 实现方向
- 横向 `flex` + `overflow-x-auto` + `snap-x`（CSS scroll snap）
- 卡片用 shadcn/ui `Card` 或自定义 pill 样式
- 建议内容从后端 API 获取（`/api/suggestions`）或前端硬编码

### 待解决
- [ ] 建议的触发逻辑（哪些场景出现）
- [ ] 是前端预设还是后端 AI 动态生成

## 6. Welcome / Prompts 欢迎页

### 交互要点
- 新会话时显示欢迎界面，替代空白聊天区
- 展示 AI 角色头像、名称、简介
- 下方是 Prompt 快捷入口（「帮我写日记」「查看今天的日程」「回忆一下上周」）
- 点击快捷入口直接发送对应消息

### 实现方向
- 居中布局，头像用 `rounded-full` + 毛玻璃背景
- 快捷入口用网格卡片或胶囊按钮列表
- 点击后触发和普通消息一样的发送流程

### 待解决
- [ ] 快捷入口列表是固定的还是可配置的
- [ ] 是否需要根据时间/场景动态调整（如早上显示「早安」入口）

## 7. 附件与多模态

### 交互要点
- 输入框支持拖拽上传文件
- 图片附件在消息中内联展示（缩略图可点击放大）
- 视频附件显示播放器
- 文件附件显示文件名 + 大小 + 下载按钮

### 实现方向
- 拖拽：`onDragOver` + `onDrop` 处理，显示拖拽高亮区域
- 图片放大：shadcn/ui `Dialog` 或自定义 lightbox
- 文件卡片：icon + 文件名 + 大小的横向布局

### 待解决
- [ ] 文件大小限制
- [ ] 支持的文件类型列表

## 实现优先级建议

| 优先级 | 组件 | 理由 |
|---|---|---|
| P0 | Bubble + Sender | 聊天核心，没有这两个没法跑 |
| P0 | Conversations | 多会话管理，基础功能 |
| P1 | Welcome / Prompts | 新用户体验 |
| P1 | Suggestion | 提升交互丰富度 |
| P2 | ThoughtChain | 需要后端配合，非阻塞 |
| P2 | 附件与多模态 | 锦上添花 |
