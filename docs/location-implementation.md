# Location V1

Location 是独立前端领域，入口为 `/app/location` 和 `/editorial/app/location`。保留 AionHome `/location` 旧页面；本次没有修改后端、Android 或定位状态机。

## 数据与组件

- `src/domain/location`：允许使用的 API、响应校验、字段归一化。配置读取只投影安全 credential 元数据，不保留原始 Key；POI 的空值、`"[]"`、缺失图片及数字字符串在这里处理。
- `src/application/location`：字段级草稿、校验、保存、独立配置/位置请求生命周期、实时失效通知与重新读取。
- `src/components/location`：PageHeader、最近位置、直接展开的静默时段、默认折叠的高级配置、POI 列表与 feature 内弹框和离开保护。

位置读取使用 `GET /api/location/status`，其中也包含 POI 缓存；配置使用 `GET/PUT /api/location/config`。主动 POI 查询仅由用户提交 `POST /api/location/poi-search` 触发。设家使用 `POST /api/location/set-home`；Key 查看/复制和清除分别使用 `POST /api/location/secrets/reveal`、`POST /api/location/secrets/clear`。

页面没有调用 heartbeat、test-sentinel、浏览器定位或线上调试接口。页面和普通组件不直接 fetch；请求统一经过现有 transport。

## 编辑语义

星期以 1=周一、7=周日序列化，允许空集合。专用时间的开始、结束分别回退到统一字段，空字符串仍是保存值；辅助生效时间不写入草稿。跨午夜按服务器当前日类别解释，相同起止表示没有静默时长。页面不计算当前是否静默，以服务端 `active` 为准。

所有表单编辑留在内存，使用统一保存操作；只有有意义的变更字段进入 PUT。新 Key 留空省略，显式清除经过确认和专用接口。请求失败保留草稿；PUT 已确认但重新 GET 失败时明确提示未完成读取确认，不宣称最终保存成功。自动重新读取只更新未编辑字段，保留本地修改。

家庭坐标和阈值修改后不立即重算页面状态或距离。后续常规 `location_update` 通知及完整状态重读用于恢复距离显示，仅更新时间戳的静默/缺 Key 心跳不会解除提示。服务端未提供配置版本，无法证明某次心跳使用了哪个配置版本；这是现有后端边界。

设家确认展示最近坐标及时间，同时说明后端执行时可能已有更新的位置；响应返回的实际坐标会用于成功反馈。设家替换家庭坐标草稿，保留其余草稿。清除已保存 Key 保留其他配置和新 Key 草稿。

应用关闭及浏览器后退由 feature 内确认弹框保护，浏览器刷新/关闭使用原生 beforeunload 提示。操作处理中阻止离开；不创建全局路由拦截框架。已保存 Key 的明文仅在明确查看/复制后短暂持有，15 秒、页面隐藏、折叠高级配置、离开或凭据引用变化时隐藏；不进入持久化、日志或普通配置响应。

## 同步与限制

- `location_update` 仅映射为失效通知及可选上报时间元数据，不用其部分 DTO 替换状态；聊天领域忽略此通知。
- 页面进入、WebSocket 初次连接/重连、重新可见、手动刷新与写入操作后重新读取。常规通知合并 200ms，配置和状态低频读取间隔 60 秒；隐藏页面不执行这些轮询或事件刷新。
- 同类读取取消较旧请求，已取消和离开后的响应不更新页面。写入期间暂停普通重新读取，确认后重读。WebSocket 认证失败停止自动重连，可显式恢复。
- `active` 只描述后端当前采集许可。时间超过 30 分钟仅作“较早上报记录”的展示提示，不代表手机离线或后端 TTL。
- 地址、天气、POI 可能来自较早缓存；刷新显示不要求手机采样，也不强制更新高德信息。
- POI 查询失败保留已读取数据，并显示失败；成功空列表采用不确定文案，因为后端会将部分高德上游失败转换为空结果。支持现有分类和自然语言关键词，无分页。
- 手动 POI 查询与手机心跳仍有后端状态整份写回的竞争窗口。前端串行提交本页操作无法消除此风险。
- 不提供地图、心跳频率、显著移动阈值或 POI 类型码编辑。

## 验证

单元测试覆盖领域契约、字段级提交、空工作日、时间继承/清除与校验、草稿保留与保存确认、Key 生命周期、操作失败、迟到响应、实时通知/重连、隐藏轮询、导航保护以及两种入口和页面语义。运行 `npm test`、`tsc --noEmit`、`npm run build`；不执行线上操作或浏览器自动化。

人工验收：

1. 在经典及 editorial 桌面进入定位，检查手机窄屏、深色/自定义主题、时间控件与星期触摸区域；窄屏星期按钮换行以保留 44px 触摸面积。
2. 修改统一和专用字段、清除单端/整组、工作日全不选；验证未保存刷新保留、关闭/后退取消与确认、浏览器刷新提醒。
3. 检查高级配置默认折叠、输入校验展开、Key 查看/复制权限、15 秒/切后台隐藏与显式清除确认。
4. 设家时检查坐标及时间说明、其他草稿保留、状态和距离等待正常上报后的行为。
5. 切换缓存分类、主动查询、查看缺图/缺评分地点详情、空结果与失败反馈；确认不会自动查询 POI。
